# 核验范围

- `python qa/verify.py`：232条原文、三经阅读页、问78–79、11项在线来源记录、30节经文、16组答案、所有站内链接和静态资源。
- `node qa/dom-check.cjs`：用jsdom 26.1.0模拟DOM，验证目录、答案、主题字号、临在视角切换、救赎节点与播放暂停、六题自测、复习保存、三经遮盖／键盘揭示与语音不可用提示。运行前可在项目根目录执行 `npm install --no-save jsdom@26.1.0`；也可用环境变量`GTSER_JSDOM`指向已有安装。

**这不是浏览器视觉检查。** 当前任务尝试连接浏览器时返回 `Local browser use is disabled in Work settings`。未通过其他控制方式绕过该设置。没有声称实际测量手机／平板／电脑的重叠、横向溢出或截图。

样式提供320px起的小屏排版、移动断点、局部表格横向滚动、原生长文滚动、减少动态效果与打印规则。上线前的静态检查不能替代终端上的实际视觉验收。后续启用浏览器控制后，建议检查320、390、768、1440px，以及夜读、大字号、目录开关和三经背诵页面。

本机语音受系统可用声音影响。本次验证了不支持语音时的降级提示，没有声称实测中文音频播放。公开部署文件的一致性另见根目录deployment.json。
